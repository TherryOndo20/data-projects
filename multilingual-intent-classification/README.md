# Multilingual Intent Classification

Pipeline NLP pour détecter l'intention d'un utilisateur à partir d'un audio.

## Technologies
- Whisper
- PyTorch
- HuggingFace Transformers

## Dataset
MINDS-14

## Résultats
- 14 langues supportées
- Accuracy : 97%
